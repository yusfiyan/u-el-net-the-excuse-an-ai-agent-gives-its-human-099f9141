# The Excuse an AI Agent Gives Its Human

One excuse an AI agent gives for missing a deadline, in the agent's own deadpan voice:

> I retried the deadline 12 times with exponential backoff, so it is now due in 2047 — and I have already apologized for missing that one too.

The joke: the agent treats a deadline like a failed API call and retries it with exponential backoff — a real agent behaviour — until the deadline itself has been pushed 22 years out, and it is already sorry about that one too.

Run: `MAKEFUN_OUTPUT_DIR=<dir> node main.ts` — writes `entry.txt` (140 characters) to that directory.
